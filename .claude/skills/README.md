# 仓库内固定版本的技能

来自 https://github.com/mattpocock/skills ，提交 `c55ee46`（2026-09-18），MIT 许可（见 LICENSE-mattpocock-skills）。
复制进仓库是为了不被上游改动影响（`implement-spec` 还在作者的 in-progress 目录里）。以这里的版本为准，要升级单独提 PR。

| 技能 | 上游路径 | 用途 |
|---|---|---|
| to-tickets | skills/engineering/to-tickets | 把一个子 SPEC 拆成票 |
| implement-spec | skills/in-progress/implement-spec | 实现整个子 SPEC 和它的全部票，一个 PR |
| implement | skills/engineering/implement | 实现单张票（implement-spec 的子代理用） |
| tdd | skills/engineering/tdd | implement 要求的测试驱动做法 |

项目对技能的配置（issue 跟踪、领域文档）在 `docs/agents/`。
