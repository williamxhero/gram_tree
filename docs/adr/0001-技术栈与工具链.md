# 0001 技术栈与工具链

- 状态：已采纳（2026-09-27，SPEC-013.1 #15）
- 背景：34 个子 SPEC 都在同一套工程上开发，选型要一开始定下，之后保持一致。换库先在这里写新的决策记录。

## 决定

### 客户端（`app/`）

| 方面 | 选择 | 理由 |
|---|---|---|
| 框架 | Flutter 3.47.5（stable） | 一套代码出 iOS 和 Android，还能编译成网页版做云端测试（见 0003） |
| 状态管理 | flutter_riverpod 3 | 依赖注入和测试替换（`overrides`）都方便，页面测试不用启动服务端 |
| 路由 | go_router（`StatefulShellRoute`） | 固定的底部五入口各自保留页面状态 |
| 本地数据库 | drift（SQLite） | 类型安全、支持迁移、有网页实现；等离线功能（SPEC-013.3）第一次用到时再加依赖 |
| 界面文字 | Flutter gen-l10n，`lib/l10n/app_zh.arb` | 首发只有简体中文，集中管理，以后加语言不改页面 |
| 崩溃上报 | sentry_flutter，指向自建 GlitchTip | 协议通用、数据不交给第三方；同意隐私政策后才初始化 |
| 静态检查 | flutter_lints + `dart format` | 官方默认 |

不引入依赖 Google Play 服务的库，保证国产 Android 手机能装。

### 服务端（`server/`）

| 方面 | 选择 | 理由 |
|---|---|---|
| 语言与框架 | Python 3.12（开发机最低 3.11）+ FastAPI + Pydantic 2 | 用户已定；AI 生态好；OpenAPI 自动生成 |
| 数据库访问 | SQLAlchemy 2（同步会话）+ psycopg 3 | 同步写法更简单；需要并发的地方再单独评估 |
| 迁移 | Alembic，只允许一个 head | 数据库结构只能通过迁移改；测试会检查模型和迁移一致 |
| 数据库 | PostgreSQL 16 + JSONB + pgvector | 父 SPEC 10.2；第一次迁移就启用 pgvector |
| 任务 | Celery + Redis（worker 带 `--beat` 跑定时任务） | 生态成熟，单机部署简单 |
| 依赖管理 | uv（锁文件 `uv.lock`） | 快，锁定可复现 |
| 格式和检查 | ruff（格式 + lint）、pyright（standard） | 一个工具管格式和 lint；类型检查 |
| 测试 | pytest，连真 PostgreSQL 和 Redis | 见 0003 |

### 接口契约

- 服务端用 FastAPI 生成 OpenAPI 描述，`tool/gen_api_client.sh` 导出到 `api/openapi.json`，再用 openapi-generator **7.16.0** 的 `dart-dio` 生成器（`serializationLibrary=json_serializable`）生成 `app/packages/gramtree_api`。
  - 选 json_serializable 而不是默认的 built_value：生成的模型是普通 Dart 类，页面测试里构造假数据更直接。
  - 生成器输出的 `pubspec.yaml` 写的是 Dart `>=3.5`，但生成的代码用到了 3.8 的 null-aware elements，脚本会改成 `>=3.8`。
  - operationId 用路由函数名（`generate_unique_id_function`），生成的方法名是 `clientConfig()` 这样的短名字。
- 导出时按正式环境的设置，示例接口（`/v1/examples`）不进客户端。
- CI 的 `api-contract` 任务重新生成并比对，不一致就失败。

## 最低系统版本复核（Flutter 3.47.5）

- Flutter 3.47.5 的默认值是 Android `minSdk` 24、iOS 工程模板部署目标 15.0（查自 SDK 里的 FlutterExtension.kt 和 iOS 模板）。SPEC 要求的 iOS 15、Android 8.0（API 26）都不低于默认值，可以直接设定：
  - Android：`app/android/app/build.gradle.kts` 的 `minSdk = 26`
  - iOS：`app/ios/Podfile` 的 `platform :ios, '15.0'`，工程里 `IPHONEOS_DEPLOYMENT_TARGET = 15.0`
- 升级 Flutter 时重新复核这一条。
