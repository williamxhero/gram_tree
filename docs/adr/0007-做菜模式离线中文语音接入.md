# 做菜模式离线中文语音接入

状态：已采用（实现仍需随应用发布模型资源后才能完成实机验收）

## 决策

做菜模式的语音能力使用 sherpa-onnx 的本地离线识别器和 `record` 的 16 kHz、单声道 PCM 流。识别器放在可替换接入层：页面只处理模型状态、转写文本和既有做菜意图，不依赖云端、Google 服务或运行时下载模型。

中文命令监听仅在用户主动开启并通过麦克风权限后启动；每个短窗口的 PCM 只保存在内存中，识别后立即清理。按住提问和命令监听不能同时占用麦克风；退出页面、取消和异常路径释放录音、订阅和原生识别器。

模型资源必须由应用发布包提供，并在应用启动前通过 `OfflineChineseModel` 显式配置路径。当前仓库不提交模型二进制，待确定发布渠道和许可证清单后再加入对应平台资源；在资源缺失时界面显示不可用，不伪造转写结果。

## 验收边界

代码级验收覆盖模型缺失时的诚实降级、五个中文命令解析/去重、按住提问生命周期和麦克风监听的互斥释放。真实中文识别、国产 Android 设备噪声表现、模型初始化和 Android 生命周期仍须在随包模型资源可用后由 CI/真机验证。
