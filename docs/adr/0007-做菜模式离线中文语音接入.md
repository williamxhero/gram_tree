# 做菜模式离线中文语音接入

状态：已采用（模型资源已随包，待补真实识别与真机验收证据）

## 决策

做菜模式的语音能力使用 sherpa-onnx 的本地离线识别器和 `record` 的 16 kHz、单声道 PCM 流。识别器放在可替换接入层：页面只处理模型状态、转写文本和既有做菜意图，不依赖云端、Google 服务或运行时下载模型。

中文命令监听仅在用户主动开启并通过麦克风权限后启动；每个短窗口的 PCM 只保存在内存中，识别后立即清理。按住提问和命令监听不能同时占用麦克风；退出页面、取消和异常路径释放录音、订阅和原生识别器。

模型资源必须由应用发布包提供，并在应用启动前通过 `OfflineChineseModel` 显式配置路径。

### 模型资源

模型随包提供，用普通 git blob 提交在仓库里，**不使用 git-lfs**：`actions/checkout@v4` 默认不取 LFS 内容（`lfs: false`），会让 CI 拿到 pointer 文本、构建出不含真实模型的产物；开 `lfs: true` 又会把每次 CI 的模型下载计进 GitHub LFS 的 1 GB/月带宽配额，几十次构建就能耗尽。普通 blob 让本地、CI 和发布构建拿到同一份文件，不需要额外工具或运行时下载。

- 来源：sherpa-onnx 官方发布 `asr-models` 里的 `sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23-mobile.tar.bz2`，归档 SHA-256 `d394cab72b17f788b8b09ffc610f5f070e610fecf022eedca2eae9e38be4f20a`，许可证 Apache-2.0（归档内 README 标注）。
- 入库文件与官方文件对应关系（重命名以固定资源名）：
  - `app/assets/models/zh/encoder.onnx` = 官方 `encoder-epoch-99-avg-1.int8.onnx`，sha256 `20d4998206e61f7aaf87f354f9cb6aa466d0ef8ae44d568fdee2f7d23672b1e2`（15,366,685 B）
  - `app/assets/models/zh/decoder.onnx` = 官方 `decoder-epoch-99-avg-1.onnx`，sha256 `5ee0f03a2768ff1d5c83ef3a493243c7935d316cd41280037b14783a3467cc78`（7,509,745 B）
  - `app/assets/models/zh/joiner.onnx` = 官方 `joiner-epoch-99-avg-1.int8.onnx`，sha256 `a7cf9d82757bdcf786059454495a9ca95e4bd7347f72473fc08d794475c36169`（1,795,562 B）
  - `app/assets/models/zh/tokens.txt` = 官方同名文件，sha256 `8b294db9045d6e5f94647f4c1eec1af4da143a75053c399611444b378ff966ac`（48,697 B）
- 编码器与连接器用的是 int8 量化版本（体积最小、官方 mobile 归档的默认配置），不是 fp32 版本；换版本必须同时更新本 ADR 的哈希。
- 应用运行时不下载模型，只读打包进 `app/assets/models/zh/` 的本地文件；资源缺失或无法初始化时界面显示不可用，不伪造转写结果。

## 验收边界

代码级验收覆盖模型缺失时的诚实降级、五个中文命令解析/去重、按住提问生命周期和麦克风监听的互斥释放。真实中文识别的运行证据（真实模型初始化 + 真实转写输出）、国产 Android 设备噪声表现和 Android 生命周期仍须补齐后由 CI/真机验证；用假识别器跑出的结果不能当作离线识别验收。
