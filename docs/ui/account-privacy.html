账号、登录与隐私同意

按 UI 规范画的 14 屏：纸底、卡片、墨色主按钮；酱红只用在“系统替你改了”和不可撤回的操作上；标题宋体，正文黑体，数字等宽。这一组页面没有换算和估算，所以不出现来源标记和“为什么”面板；账号是隐私控制类的必显内容，结构上仍是“结论一行 → 点进去看依据和明细”。

一、首次打开：同意在一切之前

同意前不联网、不启动崩溃上报、不申请权限。全文链接打开静态网页。不同意只再说明一次，仍不同意就退出，下次打开再问。

二、登录：邮箱验证码，iPhone 另有 Apple

首次登录即注册，没有单独的注册页。验证码 6 位，10 分钟有效，60 秒后可重发（都是服务端配置项）。

三、我的 → 设置

“我的”第一眼只有昵称（结论）；账号、登录方式、隐私入口都收在设置里（明细）。退出登录只影响这台设备。

四、权限：用到才问，先说用途

统一的申请方式，本期只做框架和文案；相机、麦克风等在用到的功能里接入。示例是 SPEC-002.2 的“拍一张成品照”。

五、撤回同意与注销账号

撤回：停止采集、退出登录、回到同意页。注销：重新验证 → 看清删什么 → 确认；账号进入“注销中”，15 个工作日内删除个人数据（配置项）。

还没定、先用占位的

用户协议、隐私政策、两份清单的正文：占位文本，上线前由你提供或请律师审阅（SPEC-011）。
