模具规则

互斥

按底面积比例换算：圆模 π × 半径²，方模 边长 × 边长，长方模 长 × 宽；英寸先换成厘米（1 英寸 = 2.54 厘米）。计数食材按比例后四舍五入取整，最少 1 个。温度不变；时间只给建议，以成熟判断为准。份数调节器在模具模式下隐藏。
