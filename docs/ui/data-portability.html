公开菜谱如何处理？

有公开菜谱时必须选择，不设默认。

○ 匿名保留

作者显示“已注销用户”。公开版本继续可用，删除成品图和草稿。

○ 下架

菜谱内容和照片删除，仅保留来源关系所需的菜名、版本与 ID。

别人的改良版来源和做菜时保存的内容不受影响。确认后立即退出，账号不能再登录。
