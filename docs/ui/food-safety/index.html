鸡肉需要确认中心熟透

用食品温度计测肉最厚处，中心达到 75°C；没有温度计时，切开确认中心无粉红、没有血色，汁液清澈。

依据：香港食物安全中心“彻底煮熟”指引。温度是优先判断，外观只是无温度计时的参考。
!
不要只看炒了几分钟

表面变白、锅温或计时不能替代中心温度；修改时间、火候或温度后会重新检查。

为什么：中心未熟透可能仍有致病细菌，安全结论必须对应具体步骤。
